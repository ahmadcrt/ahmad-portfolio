# AHMAD YUNUSA — Portfolio

Personal portfolio of **Ahmad Yunusa**, Web Developer & Graphic Designer (Nigeria, working with clients worldwide).

Live site: https://ahmadcrt.github.io/ahmad-portfolio/

Built with HTML5, CSS3 and vanilla JavaScript. Hosted on GitHub Pages.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure, SEO tags, services and contact links |
| `style.css` | All styling |
| `data.js` | **Edit this to update the site**: contact settings, projects, skills and graphic designs |
| `script.js` | Renders the page from `data.js` (no need to edit) |
| `404.html`, `robots.txt`, `sitemap.xml`, `site.webmanifest` | Site identity and search engine files |
| `images/` or `assets/design/` | Graphic design images (`graphic-design-01.jpg` to `08.jpg`) |
| `assets/projects/` | Optional own screenshots, named like `nova-digital.jpg` |

## Updating
- **New project:** copy a block in the `PROJECTS` list in `data.js` and fill in the fields.
- **New design:** add the image to `images/` and a line to the `DESIGNS` list in `data.js`.
- **Contact details:** change `CONFIG` in `data.js` and the links in `index.html`.

The eight graphic designs are self-initiated concept projects for fictional brands, not client work.
