More pieces: name them ...-02.jpg, ...-03.jpg and add a line for each in script.js (see the DESIGNS list).

For fast loading: width about 1200-1600 px, JPG quality about 80, ideally under 300 KB each.
File names must be lowercase and match exactly (.jpg, not .JPG or .jpeg).
